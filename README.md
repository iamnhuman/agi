# ИИзм — атлас нейрохудожников

Каталог из 100 записей: 77 зарубежных и 23 русскоязычных. Карточки, список, интерактивная карта, поиск, разделы и кураторская `/admin`.

## Разработка

Node.js 22.13+; `npm ci`, `npm run dev`. `npm run build` собирает Worker. D1 объявлен в `.openai/hosting.json`; схема в `db/schema.ts`, миграции в `drizzle/`. Локальную миграцию можно применить после сборки через Wrangler, используя `dist/server/wrangler.json` и `.wrangler/state`.

## Данные и доступ

Исходная коллекция хранится в `lib/seed.json`. Изменения, новые карточки, удаления и разделы сохраняются в D1, а не в браузере. Миграции не содержат тестовых данных. Первый вход в кураторскую закрепляет ID владельца в базе. Сайт первоначально приватный: до любого расширения доступа владелец должен один раз открыть `/admin`, чтобы закрепить свой аккаунт. Все операции записи проверяют аккаунт на сервере и Origin.

## Импорт

Поддерживаются публичные ссылки Instagram и Telegram, включая посты. Сервер запрашивает доступные Open Graph данные с ограничением размера и времени; редиректы запрещены. Если площадка не отдаёт метаданные, создаётся редактируемый черновик из URL. Поля проверяются перед сохранением. Для ссылок на посты имя иногда нужно указать вручную. Изображения по внешним ссылкам могут стать недоступны; в этом случае карточка возвращается к абстрактной обложке. Обложки по умолчанию не являются работами художников.

## Проверено

Сборка, TypeScript, импорт Telegram в браузере, импорт Instagram с резервным заполнением, создание/чтение/изменение/удаление в локальной базе, защита от анонимной записи и чужого Origin, запрет произвольных адресов, поиск через WebMCP, мобильная верстка.
